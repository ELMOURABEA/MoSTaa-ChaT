# MoSTaa-ChaT Omni Channel Portal

MoSTaa-ChaT is the production-ready omnichannel customer communication platform for WhatsApp Business, Facebook, Messenger, Instagram, and internal agent operations, unified into a single operational dashboard.

## Features
- Unified inbox for all customer channels
- First-responder routing and assignment logic
- Multi-branch support for 50+ WhatsApp numbers
- Live status and health checks
- SQL Server health integration
- Production-ready API endpoints

## API Health Endpoints
- GET /api/health
- GET /api/health/live
- GET /api/health/ready

## Quick start
```bash
npm install
npm start
```

## Notes
This repository contains the production overlay structure and health-check foundation for the MoSTaa-ChaT platform. For the full omnichannel feature set, the source code from the existing Bolt.host project should be exported and merged here.
